# 另一天 · 校园重生计划

一款适合思政课堂的中文互动叙事小游戏：抽取身份，经历三个选择，再交换身份看见同一晚的另一面。

第一章「那盏还没亮的走廊灯」包含住校学生与宿管值班员两个视角、六个决策节点、逐项反馈、四种叙事总结，以及重生前后的选择对照。无道德评分，无付费资源，无外部字体、脚本或运行依赖。

## 使用

直接打开 `index.html`，或放到任意静态网站服务（包括 GitHub Pages）。手机、平板和电脑均可使用。

1. 输入可选昵称，随机抽取一个身份。
2. 完成三次选择，阅读选择产生的即时影响。
3. 交换身份，了解另一侧的处境，再完成三次选择。
4. 查看两轮对照，写下自己的反思。
5. 根据需要导出匿名 JSON 记录，自行交给老师。

课堂放映室提供 12—15 分钟活动流程、讨论问题、匿名选择汇总及自愿分享的手记。老师可以导入多个 JSON 文件，重复记录按 ID 去重。统计对象是完成体验次数，不是独立人数。

## 版本边界与数据

- 这是静态课堂体验版，没有服务器、账号系统、房间码、远程实时统计或老师同步控制学生进度。
- 进度与记录仅保存在当前浏览器 localStorage，最多保留 1000 条完成记录。跨设备不会同步；清除浏览器数据会删除进度。存储不可用时仍可体验并导出。
- 导出不含昵称。仅在玩家主动勾选时包含感想；请勿填写个人信息。汇总文件和手记不应提交到公开源码仓库。
- 同一人在此设备重玩会产生另一条记录；重复导入同一 ID 不会重复计数。
- 故事文本全部为虚构，无第三方素材。无广告和访问分析代码；托管平台可能按自己的隐私政策记录访问日志。
- 第二轮通过「另一侧的记忆」引用第一轮实际选择；各情境围绕共同事件展开。结局按选择关注点生成，不声称完整模拟现实维修流程，不代表职业或品德评价。

## GitHub Pages

将本目录文件上传到公开仓库根目录，在仓库 Settings → Pages 选择 Deploy from a branch，分支 main，目录 / (root)，保存。Pages 构建完成后即可分享网站链接。

## 修改剧情

- `story.js`：身份、两组各三段情境、选项、即时反馈与结局规则。
- `app.js`：进度保存、页面渲染、匿名记录导入导出。
- `style.css`：响应式布局及米白/朱红视觉样式。
- `index.html`：页面入口。

调整剧情结构或记录含义时，更新 `STORY_VERSION` 和存储键，避免旧数据被误读。发布前使用浏览器验证两个起始身份、全部六个选择、刷新续玩、结果导出/导入和手机布局。
