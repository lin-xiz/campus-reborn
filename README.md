# 另一天 · 校园重生计划

适合思政课堂的中文互动叙事小游戏。06:30 醒来，随机成为一位校园工作者，走过从清晨到 21:00 的一天，再随机成为另一人。结合两段人生的具体选择，讨论人生目的、人生态度与人生价值，写下手记和一周行动计划。

**[打开公开试玩网站](https://lin-xiz.github.io/campus-reborn/)**

## 一日篇玩法

- 六种身份：食堂阿姨、保洁人员、辅导员、教授、讲师、图书管理员。没有学生可玩身份，首页人物卡仅作介绍，不能手动选择。
- 每次从六种身份中随机抽取；第二轮从余下五种中抽取，保证两轮身份不同。抽签结果立即保存，刷新后通过“继续上次体验”恢复，不会重新抽签。
- 每个角色七个时刻：06:30、08:00、10:00、12:30、15:30、18:30、21:00。共 42 个情境、126 个选项，每局体验两种角色、完成 14 次选择。
- 六种职业有对应的原创 SVG 场景：食堂、教学楼门厅、辅导员办公室、实验室、课堂、图书馆；傍晚交接或回归个人生活，夜间在家回望。不是让所有角色连续工作到夜里。
- 每个选择呈现即时反馈，可回看上一选择；第二轮会对照第一轮同一时刻的经历。剧情采用固定时刻与不同反馈，不模拟无限分支。

## 使用

直接打开 `index.html`，或放到静态网站服务（如 GitHub Pages）。无构建步骤，无外部字体、付费资源或运行依赖。

1. 点击“随机开启新人生”，输入可选称呼，留下出发前的关注点。
2. 随机抽取身份，查看专属场景，完成七个时刻的选择。
3. 再次随机重生，成为另一种角色，度过完整的一天。
4. 查看十四次选择对照、人生观三个问题的复盘，写下手记与一周行动计划。
5. 按需导出匿名 JSON 记录，自行交给老师。

独立体验约 20—25 分钟，课堂讨论建议 30—35 分钟，可依据阅读速度调整。课堂放映室提供讨论引导、选择汇总和自愿分享的手记。老师可手动导入多个 JSON 文件，按 ID 去重。统计对象是完成体验次数，不是独立人数；每个岗位以实际体验该岗位的记录为比例分母。

## 教学设计

剧情从具体劳动出发，涉及被忽视的贡献、误解与挫折、个人休息与岗位责任、求助与隐私、研究进度与求真、共享资源与公平，以及个人发展和服务他人的联系。下午与晚间情境进一步追问：善意怎样变成持续的支持，个人需要怎样被尊重，一天的意义是否只能由头衔或成果数量衡量。

结尾依据玩家的实际选择讨论：人生目的——我希望自己的劳动回应什么需要；人生态度——面对困难怎样继续行动；人生价值——自我价值与社会价值如何在实践中相互促进。最后落实到“何时、在哪里、做什么、怎样检验”的行动计划。不提供品德排名，不用一次选择推断人格或完整人生观。

课程概念参考：[国家高等教育智慧教育平台《思想道德与法治》课程](https://higher.smartedu.cn/course/69052e085345b68214577315)。人物、故事和插画为原创虚构内容，不代表整个职业的全部处境；教师可结合教学安排调整。

## 数据与版本

- 静态体验版，没有账号、服务器、房间码、实时联网统计或教师远程控制。
- 进度与记录只存在当前浏览器 localStorage，最多保存 1000 条完成记录。跨设备不自动同步，清除浏览器数据会删除进度。存储不可用时仍可在当前页面体验并导出。
- 匿名导出不含称呼、出发想法；只有主动勾选分享后才包含手记和行动计划。请勿填写个人信息，也不要把课堂记录上传到公开源码仓库。
- 同一设备重新体验会生成新的记录；重复导入同一 ID 不重复计数。
- 一日篇使用 `campus-day-v4` 数据格式及独立存储键。旧清晨版和夜间版记录不自动混入新统计；旧数据不会被新版本删除，旧源码仍可从 GitHub 历史查看。
- 无广告或访问分析代码；托管服务可能按自身政策记录访问日志。

## 开发与部署

把本目录上传至仓库根目录，在 Settings → Pages 选择 `main` 分支的根目录发布。

文件分工：`story.js` 为身份、情境、反馈与总结；`app.js` 为随机抽取、状态验证、续玩和导入导出；`ui.js` 为游戏界面、复盘与课堂汇总；`environments.js`、`portraits.js`、`campus-morning.svg` 为原创矢量插画；`style.css` 为响应式样式；`index.html` 为入口。

调整剧情结构或记录含义时，更新 `STORY_VERSION`、存储键与入口文件中的资源版本号，避免旧数据被误读。

使用 `node verify.cjs` 运行无依赖验证：覆盖全部 30 种有序角色组合的 900 条路径、25,200 个过程存档状态、两轮抽签存档、随机抽取边界与不重复规则、42 个场景渲染、四种总结可达性、隐私导出和文本转义。发布前另在浏览器中检查完整十四次选择、刷新续玩、导入导出及手机布局。
