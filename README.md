# 另一天 · 校园重生计划

一款适合思政课堂的中文互动叙事小游戏。早上 06:30 醒来，自主选择一个校园工作者的身份，经历五个情境，再选择另一种身份重生。最后结合自己的实际选择，思考人生目的、人生态度、人生价值，并写下一周行动计划。

**[打开公开试玩网站](https://lin-xiz.github.io/campus-reborn/)**

清晨篇包含六种可选身份：食堂阿姨、保洁人员、辅导员、教授、讲师、图书管理员；没有学生可玩身份。每个身份都有独立的五段清晨故事，时间为 06:30、07:10、08:00、09:10、10:30，共三十个情境、九十个选项。每局体验两种不同身份，完成十次选择。

采用原创 SVG 清晨校园插画和六种人物插画。无付费资源、外部字体、脚本或运行依赖；没有品德评分或职业高低排名。

## 使用

直接打开 `index.html`，或放到任意静态网站服务（包括 GitHub Pages）。手机、平板和电脑均可使用。

1. 输入可选昵称，留下出发前的关注点，自主选身份（也可随机推荐）。
2. 完成五次选择，阅读情境、取舍和即时反馈。
3. 时间回到清晨，选择另一个身份，再体验五个情境。
4. 查看十次选择对照、人生观三个问题的复盘，写下手记和一周行动计划。
5. 根据需要导出匿名 JSON 记录，自行交给老师。

独立体验约 15—20 分钟。课堂放映室提供 20—25 分钟活动流程、人生观讨论问题、匿名选择汇总及自愿分享的手记。老师可以导入多个 JSON 文件，重复记录按 ID 去重。统计对象是完成体验次数，不是独立人数；每个岗位的选择比例以实际体验该岗位的记录为分母。

## 教学设计

剧情覆盖劳动被忽视、被误解或被评价、个人休息与岗位责任、真实求助与隐私、科研进度与求真、公共资源与公平、个人发展与服务他人等具体取舍。

复盘从玩家实际选择出发，分别讨论：人生目的——我希望自己的劳动回应什么需要；人生态度——怎样认真面对困难并继续行动；人生价值——自我价值与社会价值如何在实践中相互促进。最终落实到“何时、在哪里、做什么、怎样检验”的行动计划。一次选择不用于推断人格、品德或完整人生观。

概念框架参考：[国家高等教育智慧教育平台《思想道德与法治》课程](https://higher.smartedu.cn/course/69052e085345b68214577315)。具体情境与教学引导为原创，教师可结合教学安排调整。

## 版本边界与数据

- 这是静态课堂体验版，没有服务器、账号系统、房间码、远程实时统计或老师同步控制学生进度。
- 进度与记录仅保存在当前浏览器 localStorage，最多保留 1000 条完成记录。跨设备不会同步；清除浏览器数据会删除进度。存储不可用时仍可体验并导出。
- 导出不含昵称或出发想法。仅在玩家主动勾选时包含手记和行动计划；请勿填写个人信息。汇总文件和手记不应提交到公开源码仓库。
- 同一人在此设备重玩会产生另一条记录；重复导入同一 ID 不会重复计数。
- 故事文本全部为虚构，无第三方素材。无广告和访问分析代码；托管平台可能按自己的隐私政策记录访问日志。
- 角色内部为五段连续情境，选项呈现不同即时反馈；后续时刻可以回看上一选择。第二轮引用第一轮同一时刻的选择进行比较，不把不同职业写成完全相同的事件，也不声称模拟无限分支。
- 清晨篇使用独立的 `campus-morning-v3` 数据格式与存储键。旧版夜间故事不会自动导入或混入新统计；旧版源码仍可通过 GitHub 历史查看。

## GitHub Pages

将本目录文件上传到公开仓库根目录，在仓库 Settings → Pages 选择 Deploy from a branch，分支 main，目录 / (root)，保存。Pages 构建完成后即可分享网站链接。

## 修改剧情

- `story.js`：六种身份、三十段情境、选项、即时反馈与结局规则。
- `app.js`：状态与数据验证、进度保存、匿名记录导入导出。
- `ui.js`：游戏页面、人生观复盘及课堂汇总。
- `portraits.js`、`campus-morning.svg`：原创人物和校园矢量插画。
- `style.css`：响应式布局及暖色清晨视觉样式。
- `index.html`：页面入口。

调整剧情结构或记录含义时，更新 `STORY_VERSION` 和存储键，避免旧数据被误读。使用 `node verify.cjs` 运行无依赖验证：覆盖全部三十种有序身份搭配的九百条确定性测试路径、存档状态、四种总结的可达性、角色统计分母、导出隐私与导入文本转义。另需在浏览器中验证十次选择、刷新续玩、文件导入导出和手机布局。
